# Experimental TDF writer checkpoints

`SDK.NewResumableTDFWriter` creates a segment writer whose encryption and ZIP
archive state can be reconstructed after an interruption. This is a writer API;
callers own the source, emitted ciphertext, storage transport, and persistence.
Custom assertions are currently unsupported.

The methods are:

- `SegmentSize()` returns the configured plaintext segment size.
- `WriteSegment(ctx, index, data)` returns ciphertext and any ZIP prefix.
- `Snapshot()` captures a quiescent writer before finalization.
- `RestoreResumableTDFWriter(snapshot)` reconstructs a writer without the original
  SDK client or another key access request.
- `Finalize(ctx)` returns the manifest and ZIP footer after all segments are
  written.

Serialize all access to a writer. Fully consume a segment's returned ciphertext
and save the corresponding transport state before capturing a snapshot. A
snapshot records encryption state, completed segment integrity metadata, and ZIP
accounting; it does not contain previously emitted ciphertext or source bytes.

On recovery, restore the writer and continue with the next source segment and
index. Preserve acknowledged ciphertext. If a storage request had an uncertain
outcome, replay its exact previously generated bytes rather than encrypting that
segment again. Append the final manifest and archive footer to the assembled
ciphertext when writing finishes.

Snapshot bytes contain the plaintext data encryption key. Keep them private in
memory, or authenticate and encrypt them before persistence. Never log them.
Restore accepts trusted snapshots or snapshots from authenticated storage; JSON
validation does not authenticate their contents. The format is versioned and
currently experimental. Neither the writer nor its snapshot manages storage
sessions, retention, durable checkpoint ownership, or process crash recovery.

Unit tests reconstruct a fresh writer and verify complete TDF decryption and
integrity, preservation of the encryption key and usage count, and rejection of
invalid snapshots.
